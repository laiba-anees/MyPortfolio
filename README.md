
# My Portfolio Website

Welcome to my personal portfolio website! This project showcases my introduction, skills, academic background, and projects as a Computer Science student interested in Artificial Intelligence and Generative AI.

The website is designed using HTML, CSS, and JavaScript, with interactive features to provide a better user experience.

## Features

- **Home Section:** Introduction and welcome section.
- **About Me:** Personal introduction with Read More and Read Less functionality.
- **Skills Section:** Displays programming languages and technologies.
- **Projects Section:** Showcases projects with category-based filtering.
- **Project Highlighting:** Highlights project rows when hovering over them.
- **Project Selection Calculator:** Calculates the total points of selected projects.
- **Education Section:** Displays academic background.
- **Contact Form:** Interactive form with input validation and personalized messages.
- **Age Verification:** Checks age eligibility based on the entered birth year.
- **Character Counter:** Tracks the remaining characters in the special notes field.
- **Light/Dark Mode:** Allows users to switch between light and dark themes.
- **Portfolio Status:** Displays opening and closing status based on the current time.

## Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone https://github.com/laiba-anees/MyPortfolio.git
```

### 2. Navigate to the Project Folder

```bash
cd MyPortfolio
```

### 3. Run the Website

Open the `index.html` file in your preferred web browser.

You can also use the Live Server extension in Visual Studio Code for local development.
